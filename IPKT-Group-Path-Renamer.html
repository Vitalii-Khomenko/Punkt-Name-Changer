IPKT Group Path Renamer

Open one Leica IPKT file, discover point groups from their source IDs, map each group to a measurement type and path, then export final MQ point names. The file stays local in this browser tab and is never uploaded.

MQ numbering preserves original source-index gaps and can also detect missing sections from Y/X distance. With the default 3.0 m step, a distance near 6.0 m advances two MQ positions. Optional bridge detection treats one or more large spans as a bridge only when short approaches exist immediately before and after the complete span. P uses suffixes 1/2, G uses 3/4, Q uses 3/4/1/2, and QL uses 1/3/4/2. Direct final-MQ output also applies the existing -0.04 m Quadro prism-height correction.
