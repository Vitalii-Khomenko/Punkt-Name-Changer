MQ numbering preserves original source-index gaps and can also detect missing sections from Y/X distance. With the default 3.0 m step, a distance near 6.0 m advances two MQ positions. Optional bridge detection recognizes each separate bounded bridge span, including rare files containing two or more bridges. Groups explicitly ending in .EX use automatic coordinate-anchored EX numbering: the first EX point starts at the nearest configured prism or rail MQ, normally four EX points share an MQ, and two points share each MQ immediately before and after a detected bridge. P uses suffixes 1/2, G uses 3/4, Q uses 3/4/1/2, and QL uses 1/3/4/2. Direct final-MQ output also applies the existing -0.04 m Quadro prism-height correction.

G = Rail path P = Prism path Q = Quadro QL = Quadro line
